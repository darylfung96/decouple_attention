A — Forecasting compute audit

What changed: Hook tests proved the earlier attention outputs are completely unused (differences exactly 0.00 across 3 configs and 3 seeds). A last-query-only forward path was built and verified bit-exact to about 5e-7, with two script bugs found and fixed along the way (normalization ordering, timing closure). The backbone decision was recorded as keep-single-block, and the appendix now lists all audit artifacts.

Canonical timing (batch of 32): full-layer Normal 47.7 / compressed 47.4 and 40.8 ms; forecast-only Normal 2.6–3.9 ms vs compressed 5.8–9.5 ms. Honest finding: the plain baseline's forecast path is the fastest because it pays no compressor work. Both costs are reported.
MOSTLY DONE — one control queued

B1 — Operator specification

What changed: While documenting the routing map, the audit found the code sent three of four test cells to the wrong history blocks (only the (8,4) cell was correct). The mapping was fixed per geometry, the correct cell was verified bit-identical (difference 0.0) so its old runs stay valid, a regression test was added, and all 135 affected runs were redone. The paper now contains the full algorithm box: per-cell rules, sentinel handling, future-safety, and the historical note.

Corrected validation errors: (4,4) 0.6148, (8,4) 0.6190, (4,8) 0.6810, (8,8) 0.6128, full attention 0.8389. Realized unique blocks per query: about 14 of 64 (equal-rate) and about 10 of 32 (dual-rate), versus 96/48 dense-masked columns.

Left: one matched-budget control experiment (B1-3).

DONE (Q-2 closed 2026-09-29)

B2 — Router learning signal

What changed: A one-step gradient audit measured every parameter and found all router settings get exactly 0.000e+00 gradient in both configurations, because the hard top-k cutoff cannot carry a learning signal. Everything else (compressor, shared projections, early layers) learns normally. The decision was to disclose rather than redesign, and the paper now states in both methods and limitations that routing is frozen at startup.

DONE (plus v2 refresh 2026-09-29)

C — Factorial re-analysis

What changed: Every statistic was recomputed from the raw unrounded seeds with confidence intervals and exact tests, then recomputed again after the re-run. The interaction between the two axes turned out significant (it was not before the fix), and the old p-values were traced to an approximate test and replaced with exact ones.

Corrected values: coarser compression −0.032 (mildly helpful), coarser routing +0.030 (harmful), interaction −0.072 (p = 0.014), headline contrast +0.062 (p = 0.0074). The finding survives the fix, weaker but significant.
