# new_attention — project wiki

This collection covers the compressed-and-indexed attention paper (CSA/FSA variants)
and its pre-publication review programme, so a session can find the settled choices
without reading the trackers. qmd collection: `new-attention` (indexes `notes/`,
`sources/**/chunks`, `sources/**/digests`). Schema: [`../AGENTS.md`](../AGENTS.md).

Authoritative state lives outside the wiki and is read directly: the session resume
point is [`../pre-publication-tasks/STATUS.md`](../pre-publication-tasks/STATUS.md);
the review programme starts at `../pre-publication_v2_tasks/README.md`, then
`EXECUTION_PLAN.md`, the task file, and `RUNBOOK.md`. The wiki keeps only what
outlives a phase, because those trackers already carry the live state.
